Axion Research, email graphics v2

Rebuilt after your review. Every graphic now runs the full width of the email with no gutter and no rounded cutout, and each one is portrait so it fills a phone screen rather than sitting in the middle of one. Shown below at the real 600px desktop column and at a real 375px phone width.

What changed. v1 rendered square graphics that were placed at 320px inside a 600px column that already had padding on both sides, so they read as small cutouts stitched into a text email. These are portrait, full bleed, edge to edge.

What is still live text, on purpose. The button and the research use line are real HTML under the artwork, not part of the picture. Outlook and much of Apple Mail block images by default, so anything living only inside the graphic disappears for a chunk of the list. The headline and the offer do sit in the artwork, the way your references do.

No promo code is baked into any of these. Putting the code in the picture welds the artwork to one coupon, so if the code is renamed or never created the graphic has to be re-rendered. It lives in the email as text where it is a free edit.
