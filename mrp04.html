Fifteen arguments, fifteen compositions

Fifteen different things to say about the supply, each one built as its own composition, and each one photographed in its own world with the vial inside the scene, not a cutout on a background. The blue you asked for lives in those worlds: blue glass, blue window light, water, ice, navy lacquer. Every line of wording is set in code over the photograph, so nothing on the artwork is invented by a model. Square, composed for the feed. Every label carries the MRP mark only. There is no button on the artwork.
