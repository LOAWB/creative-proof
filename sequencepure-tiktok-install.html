TikTok base pixel

WPCode type: HTML Snippet  ·  Location: Site Wide Header  ·  Status: Active

Loads the TikTok pixel on every page and identifies the visitor when WooCommerce knows who they are. Nothing else fires without this one.

1-tiktok-base.html 
<!--
  Sequence Pure (sequencepure.com) - TikTok base pixel. SNIPPET 1 of 3.
  WPCode: HTML Snippet, Site Wide Header, Active. Install this one FIRST.

  Jason asked for WPCode snippets, not the official TikTok for Business WooCommerce plugin. This is
  the browser half's foundation: the pixel loader, one page view, and the click-id capture the
  SERVER half depends on.

  Pixel DANHHTBC77U1JKBFTBQG is already filled in below, nothing to replace. That value is the pixel's
  own Pixel Code from TikTok Events Manager (a ~20 character alphanumeric string), never an ad
  account id and never a Business Center id; the build refuses a value shaped like either.

  WHY THE CLICK-ID CAPTURE IS HERE AND NOT IN A PHP SNIPPET. TikTok attributes a server event by
  ttclid (the click id on the landing URL) and ttp (the pixel's own first-party cookie). A visitor
  lands from an ad on any page, then buys minutes or days later, and the gateway here is Tagada Pay,
  which can complete a payment from a WEBHOOK where there is no browser, no cookie and no session.
  So the click id is written to a first-party cookie the moment it is seen, and snippet 2 copies it
  onto the ORDER at checkout so snippet 3 can still read it in a webhook. Capturing it only at
  checkout would lose every visitor who did not arrive directly on the checkout page.

  The cookie is first-party, 90 days (TikTok's own attribution window for ttclid), SameSite=Lax,
  Secure, and holds only an opaque advertising click id: no email, no name, no phone.

  NOTHING HERE BRANCHES ON USER AGENT, IP, GEO OR REFERRER.
-->
<script>
!function (w, d, t) {
  w.TiktokAnalyticsObject = t;
  var ttq = w[t] = w[t] || [];
  ttq.methods = ["page","track","identify","instances","debug","on","off","once","ready","alias","group","enableCookie","disableCookie","holdConsent","revokeConsent","grantConsent"];
  ttq.setAndDefer = function (t, e) { t[e] = function () { t.push([e].concat(Array.prototype.slice.call(arguments, 0))); }; };
  for (var i = 0; i < ttq.methods.length; i++) { ttq.setAndDefer(ttq, ttq.methods[i]); }
  ttq.instance = function (t) {
    var e = ttq._i[t] || [];
    for (var n = 0; n < ttq.methods.length; n++) { ttq.setAndDefer(e, ttq.methods[n]); }
    return e;
  };
  ttq.load = function (e, n) {
    var r = "https://analytics.tiktok.com/i18n/pixel/events.js";
    ttq._i = ttq._i || {};
    ttq._i[e] = [];
    ttq._i[e]._u = r;
    ttq._t = ttq._t || {};
    ttq._t[e] = +new Date();
    ttq._o = ttq._o || {};
    ttq._o[e] = n || {};
    var s = d.createElement("script");
    s.type = "text/javascript";
    s.async = !0;
    s.src = r + "?sdkid=" + e + "&lib=" + t;
    var a = d.getElementsByTagName("script")[0];
    a.parentNode.insertBefore(s, a);
  };
  ttq.load('DANHHTBC77U1JKBFTBQG');
  ttq.page();

  // ---- click-id capture, see the comment above ----
  try {
    var q = new URLSearchParams(w.location.search);
    var clid = q.get('ttclid');
    if (clid && /^[A-Za-z0-9._-]{1,512}$/.test(clid)) {
      d.cookie = 'sp_ttclid=' + encodeURIComponent(clid)
        + '; Max-Age=7776000; Path=/; SameSite=Lax'
        + (w.location.protocol === 'https:' ? '; Secure' : '');
    }
  } catch (e) { /* never let attribution break the page */ }

Browser events (WooCommerce)

WPCode type: PHP Snippet  ·  Location: Run Everywhere  ·  Status: Active

Sends ViewContent, AddToCart, InitiateCheckout and CompletePayment from the shopper's browser as they move through the store.

2-tiktok-woo-browser.php 
/**
 * Sequence Pure (sequencepure.com) - TikTok browser events for WooCommerce. SNIPPET 2 of 3.
 * WPCode: PHP Snippet, Run Everywhere, Active. Install AFTER snippet 1 (the base pixel).
 *
 * WHY THIS IS PHP AND NOT MORE HTML. Snippet 1 is a static site-wide header snippet, which is all a
 * base pixel and a page view need. Every event below needs WooCommerce data that only exists in PHP
 * (the product on screen, the cart total, the order on the receipt), so it cannot live in an HTML
 * snippet. Jason's instruction was WPCode rather than the official plugin; it was not "one snippet".
 *
 * EVENTS, and why each is shaped this way. TikTok's standard ecommerce events are ViewContent,
 * AddToCart, InitiateCheckout, AddPaymentInfo, PlaceAnOrder and CompletePayment.
 *
 *   ViewContent       single product page. value = price, currency, contents[].
 *   AddToCart         classic product form adds (queued in the Woo session, printed on the next page
 *                     load, carries value) AND ajax add-to-cart buttons (the added_to_cart JS event,
 *                     NO value: that button markup carries a product id and never a price, and an
 *                     invented value is worse than an absent optional one).
 *   InitiateCheckout  checkout page only, never the receipt.
 *   CompletePayment   thank-you page, event_id sp_purchase_<order id>.
 *
 * THE ONE THING THAT MUST NOT DRIFT: CompletePayment here and CompletePayment in snippet 3 send the
 * SAME event_id, sp_purchase_<order id>, because TikTok dedupes on event_source_id + event_id +
 * event. Change the format in one file and every sale is counted twice. Both files build it through
 * the same documented format and tests/harness.php asserts they agree.
 *
 * INITIATECHECKOUT EVENT ID IS NOT WooCommerce's get_cart_hash(). On a live WooCommerce store that
 * value changed between two plain refreshes of /checkout/, so it counted one shopper several times
 * while every offline test still passed. The key here is built from sorted product id x quantity,
 * which is stable across a refresh by construction.
 *
 * ORDERING IS NOT ASSUMED. Snippet 1 is an HTML header snippet and this is a PHP snippet, so which
 * prints first is not guaranteed. Every call runs immediately if window.ttq already exists and on
 * DOMContentLoaded otherwise, and never throws if snippet 1 is missing.
 *
 * POLICY. No advanced matching in the browser (no email, phone or name) and NO PRODUCT NAMES: this
 * is a research peptide catalogue and compound names in event properties are the documented
 * rejection shape on ad platforms. content_id is the WooCommerce product id and nothing else.
 * Nothing branches on user agent, IP, geo or referrer.
 *
 * ALSO DOES ONE SERVER-SIDE JOB: it copies the TikTok click ids onto the order at checkout, which is
 * what lets snippet 3 attribute a payment that completes later in a Tagada Pay webhook where there
 * are no cookies at all. See sp_ttk_persist_click_ids().
 *
 * KILL SWITCH: define( 'SP_TTK_BROWSER_EVENTS', false ); turns every browser event here off without
 * deactivating the snippet. The click-id persistence keeps running, because turning off reporting
 * should not silently destroy attribution data you cannot recover later.
 *
 * LIMIT: block-based (Store API) cart adds fire no AddToCart here. ViewContent, InitiateCheckout and
 * CompletePayment still fire.
 */

function sp_ttk_browser_on() {
	return ! ( defined( 'SP_TTK_BROWSER_EVENTS' ) && ! SP_TTK_BROWSER_EVENTS );
}

function sp_ttk_json( $v ) {
	// HEX_TAG: a value containing </script> can never close the tag early.
	return wp_json_encode( $v, JSON_HEX_TAG | JSON_HEX_AMP | JSON_UNESCAPED_SLASHES );
}

function sp_ttk_currency() {
	return function_exists( 'get_woocommerce_currency' ) ? strtoupper( (string) get_woocommerce_currency() ) : 'USD';
}

/**
 * THE SHARED EVENT ID FORMAT. Snippet 3 has a byte-identical copy of this function under its own
 * name and tests/harness.php asserts the two produce the same string for the same order id.
 */
function sp_ttk_purchase_event_id( $order_id ) {
	return 'sp_purchase_' . (string) $order_id;
}

function sp_ttk_track( $event, $props = array(), $event_id = '' ) {
	$args = sp_ttk_json( $event ) . ', ' . sp_ttk_json( (object) $props );
	if ( '' !== $event_id ) {
		$args .= ', ' . sp_ttk_json( array( 'event_id' => (string) $event_id ) );
	}
	$js = 'ttq.track(' . $args . ');';
	echo "\n<script>(function(){var f=function(){try{" . $js . "}catch(e){}};"
		. "if(window.ttq&&window.ttq.track){f();}"
		. "else if(document.readyState==='loading'){document.addEventListener('DOMContentLoaded',f);}"
		. "else{f();}})();</script>\n"; // phpcs:ignore WordPress.Security.EscapeOutput
}

/** contents[] for one product. content_id only, never a name. See POLICY above. */
function sp_ttk_contents( $product_id, $qty, $price ) {
	$row = array(
		'content_id'   => (string) $product_id,
		'content_type' => 'product',
		'quantity'     => (int) $qty,
	);
	if ( null !== $price ) {
		$row['price'] = round( (float) $price, 2 );
	}
	return array( $row );
}

/* ------------------------------------------------------------------ ViewContent */
add_action( 'wp_footer', 'sp_ttk_view_content', 20 );
function sp_ttk_view_content() {
	if ( ! sp_ttk_browser_on() || ! function_exists( 'is_product' ) || ! is_product() ) {
		return;
	}
	$product = function_exists( 'wc_get_product' ) ? wc_get_product( get_the_ID() ) : null;
	if ( ! $product ) {
		return;
	}
	$price = $product->get_price();
	sp_ttk_track(
		'ViewContent',
		array(
			'contents' => sp_ttk_contents( $product->get_id(), 1, $price ),
			'value'    => round( (float) $price, 2 ),
			'currency' => sp_ttk_currency(),
		)
	);
}

/* ------------------------------------------------------------------ AddToCart, classic form */
add_action( 'woocommerce_add_to_cart', 'sp_ttk_queue_add_to_cart', 20, 6 );
function sp_ttk_queue_add_to_cart( $cart_item_key, $product_id, $quantity, $variation_id, $variation, $cart_item_data ) {
	if ( ! sp_ttk_browser_on() ) {
		return;
	}
	// An ajax add is handled in the browser by the added_to_cart listener below. Queueing it here as
	// well would print the same add on the NEXT page load and count it twice.
	if ( function_exists( 'wp_doing_ajax' ) && wp_doing_ajax() ) {
		return;
	}
	if ( ! function_exists( 'WC' ) || ! WC()->session ) {
		return;
	}
	$id      = $variation_id ? $variation_id : $product_id;
	$product = function_exists( 'wc_get_product' ) ? wc_get_product( $id ) : null;
	$price   = $product ? (float) $product->get_price() : 0.0;
	$queue   = (array) WC()->session->get( 'sp_ttk_atc_queue', array() );
	$queue[] = array(
		'id'    => $id,
		'qty'   => (int) $quantity,
		'price' => $price,
	);
	WC()->session->set( 'sp_ttk_atc_queue', $queue );
}

add_action( 'wp_footer', 'sp_ttk_flush_add_to_cart', 21 );
function sp_ttk_flush_add_to_cart() {
	if ( ! sp_ttk_browser_on() || ! function_exists( 'WC' ) || ! WC()->session ) {
		return;
	}
	$queue = (array) WC()->session->get( 'sp_ttk_atc_queue', array() );
	if ( ! $queue ) {
		return;
	}
	WC()->session->set( 'sp_ttk_atc_queue', array() );
	foreach ( $queue as $row ) {
		sp_ttk_track(
			'AddToCart',
			array(
				'contents' => sp_ttk_contents( $row['id'], $row['qty'], $row['price'] ),
				'value'    => round( (float) $row['price'] * (int) $row['qty'], 2 ),
				'currency' => sp_ttk_currency(),
			)
		);
	}
}

/* ------------------------------------------------------------------ InitiateCheckout */
add_action( 'wp_footer', 'sp_ttk_initiate_checkout', 23 );
function sp_ttk_initiate_checkout() {
	if ( ! sp_ttk_browser_on() || ! function_exists( 'is_checkout' ) || ! is_checkout() ) {
		return;
	}
	// The receipt is also is_checkout(); CompletePayment owns that page.
	if ( function_exists( 'is_order_received_page' ) && is_order_received_page() ) {
		return;
	}
	if ( ! function_exists( 'WC' ) || ! WC()->cart || WC()->cart->is_empty() ) {
		return;
	}
	$contents = array();
	$key      = array();
	foreach ( WC()->cart->get_cart() as $item ) {
		$id    = ! empty( $item['variation_id'] ) ? $item['variation_id'] : $item['product_id'];
		$qty   = (int) $item['quantity'];
		$price = isset( $item['line_total'] ) && $qty > 0 ? (float) $item['line_total'] / $qty : null;
		$contents[] = array(
			'content_id'   => (string) $id,
			'content_type' => 'product',
			'quantity'     => $qty,
		);
		if ( null !== $price ) {
			$contents[ count( $contents ) - 1 ]['price'] = round( $price, 2 );
		}
		$key[] = $id . 'x' . $qty;
	}
	// Stable across a refresh by construction. NEVER get_cart_hash(), see the header comment.
	sort( $key );
	sp_ttk_track(
		'InitiateCheckout',
		array(
			'contents' => $contents,
			'value'    => round( (float) WC()->cart->get_total( 'edit' ), 2 ),
			'currency' => sp_ttk_currency(),
		),
		'sp_ic_' . md5( implode( '|', $key ) )
	);
}

/* ------------------------------------------------------------------ CompletePayment */
add_action( 'woocommerce_thankyou', 'sp_ttk_complete_payment', 20, 1 );
function sp_ttk_complete_payment( $order_id ) {
	if ( ! sp_ttk_browser_on() || ! $order_id || ! function_exists( 'wc_get_order' ) ) {
		return;
	}
	$order = wc_get_order( $order_id );
	if ( ! $order ) {
		return;
	}
	// A receipt reload must not send a second browser event. The server half (snippet 3) has its own
	// separate marker, because the two halves are meant to both fire once and dedupe on event_id.
	if ( $order->get_meta( '_sp_ttk_browser_sent' ) ) {
		return;
	}
	$contents = array();
	foreach ( $order->get_items() as $item ) {
		$id  = $item->get_variation_id() ? $item->get_variation_id() : $item->get_product_id();
		$qty = (int) $item->get_quantity();
		$row = array(
			'content_id'   => (string) $id,
			'content_type' => 'product',
			'quantity'     => $qty,
		);
		if ( $qty > 0 ) {
			$row['price'] = round( (float) $item->get_total() / $qty, 2 );
		}
		$contents[] = $row;
	}
	sp_ttk_track(
		'CompletePayment',
		array(
			'contents' => $contents,
			'value'    => round( (float) $order->get_total(), 2 ),
			'currency' => strtoupper( (string) $order->get_currency() ),
		),
		sp_ttk_purchase_event_id( $order->get_id() )
	);
	$order->update_meta_data( '_sp_ttk_browser_sent', 'yes:' . time() );
	$order->save();
}

/* ------------------------------------------------------------------ click ids onto the order */
/**
 * Runs whether or not the browser events are switched on. See the KILL SWITCH note in the header.
 * ttclid comes from snippet 1's first-party cookie, ttp is the pixel's own _ttp cookie. Both are
 * opaque advertising ids. A payment that completes later in a Tagada Pay webhook has neither, which
 * is exactly why they are copied onto the order here while a browser is still present.
 */
add_action( 'woocommerce_checkout_create_order', 'sp_ttk_persist_click_ids', 20, 2 );
function sp_ttk_persist_click_ids( $order, $data ) {
	if ( ! is_object( $order ) ) {
		return;
	}
	$clid = isset( $_COOKIE['sp_ttclid'] ) ? (string) $_COOKIE['sp_ttclid'] : '';
	$ttp  = isset( $_COOKIE['_ttp'] ) ? (string) $_COOKIE['_ttp'] : '';
	if ( $clid && preg_match( '/^[A-Za-z0-9._%-]{1,512}$/', $clid ) ) {
		$order->update_meta_data( '_sp_ttclid', urldecode( $clid ) );
	}
	if ( $ttp && preg_match( '/^[A-Za-z0-9._-]{1,512}$/', $ttp ) ) {
		$order->update_meta_data( '_sp_ttp', $ttp );
	}
	$ua = isset( $_SERVER['HTTP_USER_AGENT'] ) ? substr( (string) $_SERVER['HTTP_USER_AGENT'], 0, 500 ) : '';
	if ( $ua ) {
		$order->update_meta_data( '_sp_ttk_ua', $ua );
	}
}

Server side purchase (Events API)

WPCode type: PHP Snippet  ·  Location: Run Everywhere  ·  Status: Active

Posts the purchase to TikTok from your server, so a sale still records when the browser pixel is blocked. It shares one event id with snippet 2, so TikTok counts the sale once, not twice.

3-tiktok-events-api.php 
/**
 * Sequence Pure (sequencepure.com) - TikTok Events API, server half. SNIPPET 3 of 3.
 * WPCode: PHP Snippet, Run Everywhere, Active. Install AFTER snippets 1 and 2.
 *
 * Jason asked for WPCode snippets, not the official TikTok for Business WooCommerce plugin, so the
 * server half is this: WooCommerce payment hooks posting straight to the Events API.
 *
 * Pixel DANHHTBC77U1JKBFTBQG is already filled in below - nothing to replace.
 * The access token is NOT in this file on purpose. Put it in wp-config.php as
 * define( 'SP_TTK_ACCESS_TOKEN', '...' ); and this snippet picks it up.
 *
 * SCHEMA, verified 2026-09-19 against TikTok's live docs, do not re-research:
 *   POST https://business-api.tiktok.com/open_api/v1.3/event/track/
 *   headers: Access-Token, Content-Type: application/json
 *   body:    event_source "web", event_source_id = the Pixel Code, data[] of
 *            { event, event_time (int, seconds), event_id, user{}, page{}, properties{} }
 *   user:    email, phone, external_id are SHA-256 REQUIRED (email trimmed and lowercased first,
 *            phone normalised to E.164 first); ttclid, ttp, ip, user_agent are sent unhashed.
 *   TikTok dedupes on event_source_id + event_id + event.
 *
 * THE ONE THING THAT MUST NOT DRIFT: sp_ttk_api_purchase_event_id() below produces the same string
 * as sp_ttk_purchase_event_id() in snippet 2, sp_purchase_<order id>. If they ever disagree, TikTok
 * stops seeing the browser and server CompletePayment as one event and counts every sale twice.
 * tests/harness.php asserts the two agree, and a mutant that breaks it is a red control.
 *
 * WHY TWO HOOKS. woocommerce_payment_complete is the honest "money moved" signal and is the one that
 * fires for an asynchronous gateway. Tagada Pay is the gateway here and can complete a payment from
 * a WEBHOOK where there is no browser, no cookie and no session, which is why the click ids are read
 * off the ORDER (snippet 2 put them there) and never out of $_COOKIE. woocommerce_thankyou is the
 * backstop for a gateway that marks an order paid without firing payment_complete. The meta marker
 * makes running both harmless.
 *
 * THE MARKER MUST NOT TRAP A FAILURE. It is written only on a SUCCESSFUL post, as yes:<ts>. A failed
 * attempt writes failed:<ts>, which does NOT block a later retry: the gate tests specifically for
 * the yes: prefix, not for the meta being non-empty. A marker that blocks retry after a network
 * blip loses the sale silently and forever, and that is a red control in the suite.
 *
 * NO TEST ORDER. Do not place a real WooCommerce order to verify this. Set
 * define( 'SP_TTK_TEST_EVENT_CODE', '<code from Events Manager>' ); and the post carries
 * test_event_code so it lands in Test Events and nowhere else. Remove the constant afterwards.
 *
 * KILL SWITCH: define( 'SP_TTK_SERVER_EVENTS', false );
 * The access token is never echoed, never logged and never put in a URL.
 */

function sp_ttk_api_on() {
	return ! ( defined( 'SP_TTK_SERVER_EVENTS' ) && ! SP_TTK_SERVER_EVENTS );
}

function sp_ttk_api_pixel_code() {
	if ( defined( 'SP_TTK_PIXEL_CODE' ) && SP_TTK_PIXEL_CODE ) {
		return (string) SP_TTK_PIXEL_CODE;
	}
	return 'DANHHTBC77U1JKBFTBQG';
}

function sp_ttk_api_access_token() {
	// wp-config.php wins, so the token can be rotated without editing this snippet.
	if ( defined( 'SP_TTK_ACCESS_TOKEN' ) && SP_TTK_ACCESS_TOKEN ) {
		return (string) SP_TTK_ACCESS_TOKEN;
	}
	return ''; // set SP_TTK_ACCESS_TOKEN in wp-config.php
}

/** Byte-identical result to sp_ttk_purchase_event_id() in snippet 2. See the header comment. */
function sp_ttk_api_purchase_event_id( $order_id ) {
	return 'sp_purchase_' . (string) $order_id;
}

function sp_ttk_api_hash( $v ) {
	$v = trim( (string) $v );
	return '' === $v ? '' : hash( 'sha256', $v );
}

function sp_ttk_api_hash_email( $email ) {
	$email = strtolower( trim( (string) $email ) );
	return '' === $email ? '' : hash( 'sha256', $email );
}

/**
 * E.164 before hashing, which is what TikTok matches on. Digits only, leading +, and a US number
 * given as 10 digits gets the country code it is missing. A number we cannot normalise is DROPPED
 * rather than sent in a shape that can never match: a wrong hash is not a weaker match, it is a
 * permanent non-match that looks like a match was attempted.
 */
function sp_ttk_api_hash_phone( $phone, $country = 'US' ) {
	$raw = preg_replace( '/[^0-9+]/', '', (string) $phone );
	if ( '' === (string) $raw ) {
		return '';
	}
	if ( 0 === strpos( $raw, '+' ) ) {
		$digits = preg_replace( '/[^0-9]/', '', $raw );
		return strlen( (string) $digits ) >= 8 ? hash( 'sha256', '+' . $digits ) : '';
	}
	$digits = preg_replace( '/[^0-9]/', '', $raw );
	if ( 'US' === strtoupper( (string) $country ) ) {
		if ( 10 === strlen( (string) $digits ) ) {
			return hash( 'sha256', '+1' . $digits );
		}
		if ( 11 === strlen( (string) $digits ) && 0 === strpos( $digits, '1' ) ) {
			return hash( 'sha256', '+' . $digits );
		}
	}
	return strlen( (string) $digits ) >= 8 ? hash( 'sha256', '+' . $digits ) : '';
}

function sp_ttk_api_client_ip( $order ) {
	$ip = is_object( $order ) && method_exists( $order, 'get_customer_ip_address' ) ? (string) $order->get_customer_ip_address() : '';
	if ( '' === $ip && isset( $_SERVER['REMOTE_ADDR'] ) ) {
		$ip = (string) $_SERVER['REMOTE_ADDR'];
	}
	return filter_var( $ip, FILTER_VALIDATE_IP ) ? $ip : '';
}

add_action( 'woocommerce_payment_complete', 'sp_ttk_api_purchase', 20, 1 );
add_action( 'woocommerce_thankyou', 'sp_ttk_api_purchase', 30, 1 );
function sp_ttk_api_purchase( $order_id ) {
	if ( ! sp_ttk_api_on() || ! $order_id || ! function_exists( 'wc_get_order' ) ) {
		return;
	}
	$order = wc_get_order( $order_id );
	if ( ! $order ) {
		return;
	}
	// yes: ONLY. A failed: marker must never block a retry. See the header comment.
	if ( 0 === strpos( (string) $order->get_meta( '_sp_ttk_server_sent' ), 'yes' ) ) {
		return;
	}

	$contents = array();
	foreach ( $order->get_items() as $item ) {
		$id  = $item->get_variation_id() ? $item->get_variation_id() : $item->get_product_id();
		$qty = (int) $item->get_quantity();
		$row = array(
			'content_id'   => (string) $id,
			'content_type' => 'product',
			'quantity'     => $qty,
		);
		if ( $qty > 0 ) {
			$row['price'] = round( (float) $item->get_total() / $qty, 2 );
		}
		$contents[] = $row;
	}

	// Identifiers only. No product names, same policy as snippet 2.
	$user = array();
	$e = sp_ttk_api_hash_email( $order->get_billing_email() );
	if ( $e ) {
		$user['email'] = $e;
	}
	$p = sp_ttk_api_hash_phone( $order->get_billing_phone(), $order->get_billing_country() );
	if ( $p ) {
		$user['phone'] = $p;
	}
	if ( $order->get_customer_id() ) {
		$user['external_id'] = sp_ttk_api_hash( 'sp_cust_' . $order->get_customer_id() );
	}
	$clid = (string) $order->get_meta( '_sp_ttclid' );
	if ( $clid ) {
		$user['ttclid'] = $clid;
	}
	$ttp = (string) $order->get_meta( '_sp_ttp' );
	if ( $ttp ) {
		$user['ttp'] = $ttp;
	}
	$ip = sp_ttk_api_client_ip( $order );
	if ( $ip ) {
		$user['ip'] = $ip;
	}
	$ua = (string) $order->get_meta( '_sp_ttk_ua' );
	if ( '' === $ua && isset( $_SERVER['HTTP_USER_AGENT'] ) ) {
		$ua = substr( (string) $_SERVER['HTTP_USER_AGENT'], 0, 500 );
	}
	if ( $ua ) {
		$user['user_agent'] = $ua;
	}

	$body = array(
		'event_source'    => 'web',
		'event_source_id' => sp_ttk_api_pixel_code(),
		'data'            => array(
			array(
				'event'      => 'CompletePayment',
				'event_time' => (int) ( $order->get_date_created() ? $order->get_date_created()->getTimestamp() : time() ),
				'event_id'   => sp_ttk_api_purchase_event_id( $order->get_id() ),
				'user'       => (object) $user,
				'page'       => (object) array(
					'url' => function_exists( 'wc_get_checkout_url' ) ? wc_get_checkout_url() : home_url( '/' ),
				),
				'properties' => (object) array(
					'contents'     => $contents,
					'content_type' => 'product',
					'value'        => round( (float) $order->get_total(), 2 ),
					'currency'     => strtoupper( (string) $order->get_currency() ),
				),
			),
		),
	);
	if ( defined( 'SP_TTK_TEST_EVENT_CODE' ) && SP_TTK_TEST_EVENT_CODE ) {
		$body['test_event_code'] = (string) SP_TTK_TEST_EVENT_CODE;
	}

	$res = wp_remote_post(
		'https://business-api.tiktok.com/open_api/v1.3/event/track/',
		array(
			'timeout' => 15,
			'headers' => array(
				'Access-Token' => sp_ttk_api_access_token(),
				'Content-Type' => 'application/json',
			),
			'body'    => wp_json_encode( $body ),
		)
	);

	// TikTok answers HTTP 200 with a body-level code; 0 is success and anything else is not. Judging
	// on the status code alone would record a rejected event as sent.
	$ok   = false;
	$note = '';
	if ( is_wp_error( $res ) ) {
		$note = 'transport: ' . $res->get_error_message();
	} else {
		$decoded = json_decode( (string) wp_remote_retrieve_body( $res ), true );
		$code    = is_array( $decoded ) && array_key_exists( 'code', $decoded ) ? (int) $decoded['code'] : -1;
		$ok      = ( 200 === (int) wp_remote_retrieve_response_code( $res ) && 0 === $code );
		$note    = 'http ' . wp_remote_retrieve_response_code( $res ) . ' code ' . $code
			. ( is_array( $decoded ) && isset( $decoded['message'] ) ? ' ' . substr( (string) $decoded['message'], 0, 200 ) : '' );
	}

	$order->update_meta_data( '_sp_ttk_server_sent', ( $ok ? 'yes:' : 'failed:' ) . time() );
	// The note never contains the token: it is built only from TikTok's own response fields.
	$order->update_meta_data( '_sp_ttk_server_note', $note );
	$order->save();
}
